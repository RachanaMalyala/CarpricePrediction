# CarpricePrediction


🚗 Car Price Prediction
📌 Project Overview

Car Price Prediction is a Machine Learning project that predicts the selling price of a car based on different features such as brand, year, fuel type, transmission, mileage, and more.

The main goal of this project is to build a model that can estimate car prices accurately using historical data.

🎯 Objective

To analyze car dataset

To find important factors affecting car price

To build a machine learning model for price prediction

To evaluate the model performance

📊 Dataset Features

The dataset contains features like:

Car Name

Year

Present Price

Fuel Type

Seller Type

Transmission

Number of Owners

Kms Driven

⚙️ Technologies Used

Python

Pandas

NumPy

Matplotlib / Seaborn

Scikit-learn

🔍 Steps Involved
1️⃣ Data Collection

Imported dataset (CSV file)

Loaded using Pandas

2️⃣ Data Preprocessing

Checked for missing values

Converted categorical data into numerical form

Feature selection

3️⃣ Exploratory Data Analysis (EDA)

Visualized relationships between features

Identified important factors affecting price

4️⃣ Model Building

Split data into training and testing sets

Used Regression algorithms such as:

Linear Regression

Random Forest Regressor

5️⃣ Model Evaluation

Used metrics like:

Mean Absolute Error (MAE)

Mean Squared Error (MSE)

R² Score

📈 Results

The model successfully predicts car prices with good accuracy.
Random Forest gave better performance compared to Linear Regression.
